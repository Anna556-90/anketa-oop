# Практическая работа 6 — Анкеты на классах

Переработка обработчика анкет с ПР5 на ООП.

## Структура
- `people.py` — Person, Student, Teacher, AnketaError
- `registry.py` — Registry и функция parse_line
- `main.py` — запуск, вывод, сохранение
- `ankety.txt` — пример входного файла

## Формат файла
s;ФИО;почта;телефон;группа
t;ФИО;почта;телефон;кафедра

## Запуск
python main.py

Принятые анкеты сохраняются в `ok.txt`, бракованные — в `errors.txt`.
